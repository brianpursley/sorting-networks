# Sorting networks

I generated these networks with a private sorting-network constructor that I’m developing as part of my AI-assisted research into reducing comparator count and parallel depth.

The JSON files follow the SorterHunter format. Networks with up to 64 inputs also have SVG diagrams generated by [draw.py](draw.py).

The tables give the input count (`N`), comparator count (`L`), and parallel depth in layers (`D`). The `nw` list gives zero-based wire pairs in execution order. A `symmetric` value of `true` means that reversing the wire numbering preserves the set of comparators in every packed layer.

## Verification

The verifier needs Python 3.7+ and [`cadical`](https://github.com/arminbiere/cadical) on your PATH.

Run either command from the repository root.

```sh
# Check one network
python3 verify.py networks/Sort_64_521_20.json

# Check the entire catalog
python3 verify.py networks/*.json networks/large/*.json
```

Every network in the catalog passed the same check. The verifier checks the comparator count, packed depth and any declared symmetry, then asks CaDiCaL whether any binary input produces an unsorted output. For each network, CaDiCaL found this condition unsatisfiable. By the zero–one principle, the network therefore sorts inputs from any totally ordered set. [Verifier](verify.py)
